## 1. Introduction

Universal TV Remote ("the App") is a mobile application that allows users to discover, pair with, and control compatible smart TVs over a local Wi-Fi network.

This Privacy Policy explains how information is accessed, used, stored, and shared when you use the App.

## 2. Information Used by the App

### Local Network Information

The App uses local network access to discover compatible TVs and communicate with them.

This may involve accessing:

- Local IP addresses of compatible TVs
- TV device names and identifiers
- Network discovery information
- Pairing and connection status

This information is used to provide TV discovery, pairing, reconnection, and remote control functionality.

### Saved TV Information

The App may store information about previously connected TVs on your device, including device names, network addresses, device identifiers, and connection preferences.

This information helps users reconnect to their TVs without repeating the setup process.
